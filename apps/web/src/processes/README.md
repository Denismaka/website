# processes

Legacy Feature-Sliced Design v1 layer for cross-page flows (e.g. a multi-step
auth/onboarding wizard spanning several routes). FSD v2 folded this into
`features`/`widgets` and most teams no longer use it — this folder is kept
empty on purpose, per the architecture brief, and should only gain files if a
flow genuinely can't be expressed as a single feature or widget.
